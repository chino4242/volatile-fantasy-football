- (decision) Portfolio is a year-round cross-league management hub whose FOCUS shifts by season mode (in-season vs off-season toggle already shipped). Same triage surface, re-prioritized content per mode.
- (decision) Default landing behavior: triage-to-act at the TOP (urgent actions / Action Center), dashboard-to-browse (per-league cards) BELOW. Clear vertical hierarchy, not tabs.
- (decision) In-season core job: surface sub-optimal lineup flags across all teams; user confirms whether each was INTENTIONAL or a real mistake. Requires an acknowledge/'on purpose' state so intentional benches stop nagging while real mistakes stay visible.
- (decision) Off-season core job: show each team's strengths & weaknesses, then recommend concrete moves (waiver adds or trades) to strengthen the team.
- (decision) PRODUCT NATURE: consultant, not controller. The app advises; user executes on the real platform. Every recommendation is review -> deep-link out to Sleeper/Fleaflicker/Yahoo/MyFFPC. Cannot set lineups/make moves from this app. This reframes all 'actions' as recommendations-with-a-deeplink, never do-it buttons.
- (decision) Form-factor: TWO intentional surfaces. Desktop = primary/heavy-lifting (off-season analysis, strengths/weaknesses, trade planning, full dashboard). Phone = quick-hit (evaluate incoming trades during the day, glance at what needs attention this week). Design desktop-rich + mobile-focused-triage, not just a responsive squeeze.
- (decision) Lineup-flag interaction: flag -> review -> either deep-link to the platform to fix, OR acknowledge-as-intentional so it stops nagging. Acknowledge persists until the matchup/week changes.
- (decision) Urgency model v1: 'needs attention this week' granularity. No countdown timers / kickoff clocks in v1. Keep it calm.
- (decision) Action Center grouping is SEASON-ADAPTIVE: in-season group BY ACTION TYPE (Lineup fixes / Waiver adds / Trades to review, league nested within) for batch processing; off-season group BY TEAM (strategize team-by-team). The grouping flips with the season toggle.
- (decision) Action Center contains ONLY clear recommended actions (deep-linkable, like the buy/sell board and equivalents). Passive team-health/observations (contender label, core age, strengths/weaknesses) live in the dashboard BELOW, not the Action Center.
- (decision) Pending/incoming trades are auto-pulled for FLEAFLICKER ONLY at the moment; no other platform exposes them yet. 'Trades to review' Action Center items are thus Fleaflicker-only auto items today.
- (assumption) Because auto trade-alerts are Fleaflicker-only, the UI should set honest expectations (e.g. scope the trade section to Fleaflicker, or offer a manual 'evaluate a trade' entry point for other platforms) rather than silently showing trade alerts for only some leagues. To confirm with Chino.
- (decision) Trades in Action Center: BOTH (a) auto Fleaflicker items with a small '(Fleaflicker)' scope note AND (b) a manual 'Evaluate a trade' entry point so a texted Sleeper/Yahoo/MyFFPC offer can be plugged in. Trade-eval available everywhere; auto only for Fleaflicker.
- (decision) Quiet/empty state: when nothing is urgent, Action Center shows a calm 'You're all caught up — nothing needs attention' with the dashboard right below. It does NOT force a proactive next-best suggestion into the urgent slot (proactive value moves stay in the dashboard/off-season sections).
- (decision) Visual language: reuse the existing app design system (zinc neutrals + indigo accent, rounded-xl cards, ring-1 borders, lucide icons, dark-mode support). Do NOT invent a new palette — extend the established one. Add semantic urgency colors already in use: amber=attention/lineup, green=positive/buy, red=sell/negative.
- (event) Low-fi HTML wireframe rendered (.working/wireframe-hub.html): 4 states — (A) in-season Action Center grouped by action type with acknowledge/'on purpose' + Fleaflicker trade scope + manual evaluate-a-trade; (B) off-season grouped by team with strengthen-moves; (C) quiet 'all caught up'; (D) mobile quick-hit collapsed groups.
- (decision) Chino dislikes the dark-mode wireframe styling; primary design target is LIGHT mode (dark mode still supported by the app, but design/mocks lead with light). Re-render wireframe in light.
- (decision) Acknowledge model simplified: tapping 'On purpose' just drops the lineup flag from the urgent list for the week (resets next week). No 'X intentional (show)' collapsed audit line — that was too fussy/unclear.
- (decision) Dashboard keeps RICH health info in BOTH seasons (contender/rebuild label, core age, weakest starter, strengths/weaknesses). Not minimized in-season.
- (change) Action Center feels 'smashed together' in the wireframe. FIX in hi-fi: give each action-type group clear separation (whitespace + distinct headers, each group as its own sub-card/section within the Action Center) rather than one dense wall of rows. Spacing/hierarchy is the priority refinement.
- (decision) Trade group order in-season confirmed fine (Lineups, then Trades, then Waivers).
- (event) Hi-fi in-season key-screen mock rendered (.working/mock-hub-inseason.html) in real light zinc/indigo theme. Each action-type group is now its own breathing sub-card with a soft-tinted header (amber lineups / indigo trades / green waivers), generous padding, and clear separation — resolving the 'smashed together' feedback. Dashboard cards keep rich health info.
- (decision) Dashboard groups teams into 3 UNIFIED bands (Top / Middle / Lower) regardless of format so all leagues sort into the same visual tiers. Each card shows FORMAT-APPROPRIATE label text + a dynasty/redraft badge. Dynasty: Contender/Middle/Rebuild (value x age, via labelTeam). Redraft: value-percentile only, no 'rebuild'.
- (assumption) Proposed redraft tier wording: Contender / In the mix / Falling behind. Pending Chino confirmation vs alternatives.
- (decision) Redraft tier wording CONFIRMED: Contender / In the mix / Falling behind. Dashboard groups into 3 bands (Top / Middle / Lower); within a band sort needs-action-first; bands expanded by default on desktop (collapsible as nice-to-have).
- (event) Hi-fi off-season key-screen mock rendered (.working/mock-hub-offseason.html): Action Center grouped BY TEAM (each team sub-card: tier pill + format badge + weakness note, then add/trade/sell moves with deep-links). Dashboard banded into Top tier / Middle / Lower tier with per-team strengths & weaknesses; redraft cards use 'Contender / In the mix / Falling behind', dynasty uses 'Contender / Middle / Rebuild'.
